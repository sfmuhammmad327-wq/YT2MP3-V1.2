Running the Web Version

This browser page is just the front end — conversions are done by a small local backend that has to be running on your own machine.

Before you convert

Open a terminal in the project folder and start the backend once per session:

node server.js

Leave that terminal window running — the page talks to it at http://127.0.0.1:5000. If a conversion says "Server rejected request" or "Lost connection to local server.js", this is almost always why.

Seeing "exit code 1"?

YouTube occasionally blocks one client profile while another works fine. The backend already retries automatically across several client profiles on its own — but if it still fails after that, it's usually a temporary block on YouTube's side, not a broken setup. Just hit Convert again; it commonly succeeds within a try or two.
